# Exemplos independentes de referência

```bash
python -m visual_fidelity motion-objects examples/motion_kit/target.json
python -m visual_fidelity motion-objects examples/motion_kit/keyhole.json
```

Cada comando cria PNGs RGBA, scene.blend e recipe.json na saída indicada. Ajuste tamanho, duração, câmera, cores, material e root_keyframes no JSON. São exemplos genéricos de 2 segundos; não contêm as palavras nem os tempos do vídeo de teste.
