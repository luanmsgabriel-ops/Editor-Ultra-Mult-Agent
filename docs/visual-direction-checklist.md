# Direção visual de referência: revisão por versão

O fluxo usa mídia local. Não copie referência, fonte licenciada, credencial ou material de cliente para o Git. Separe relatório privado de documentação reproduzível com material sintético/autoral.

| Etapa | Prova exigida |
| --- | --- |
| Modo | Só efeitos = uma referência, vídeo novo autoral. Aplicação = referência e bruto autorizado. Análise = sem render. |
| Análise | Manifesto do relógio e inventário por intervalo, observado separado de hipótese e do não verificável |
| Direção | Receita compatível com a versão do motor, camadas, posições, curvas, ordem, máscaras e limiar declarado antes do teste |
| Assets | Fonte exata licenciada ou tipografia criada no chat (SVG apenas para frase conhecida, OTF/TTF com caracteres verificados para fonte completa); ícone autoral criado no chat, com silhueta/material, transparência e âncora verificados. Não use substituta silenciosa. |
| Render | MP4 real ligado/desligado no mesmo relógio; ativos autorais no modo autônomo, PTS/áudio protegidos; hashes para identificar versões |
| Revisão | Referência e candidato alinhados por evento, não por índice puro. Comparar controle/candidato na região-alvo e fora dela antes da compressão e após decodificar a exportação. Revisar cortes, tracking e oclusões em movimento. Se houver tela de revisão, confirmar que ela abre, navega para o efeito e reproduz o artefato certo. |
| Reutilização | Fixture sintética/autoral para regressão; positivo em novo material real compatível e negativo se o operador puder disparar indevidamente. |
| Publicação | Só após autorização e validação: teste em cópia limpa; revisão de licença de código, dependências, mídia e fontes; verificar histórico/branches por credenciais e material privado. Nenhuma dessas checagens autoriza alterar visibilidade. |

## Ficha de evolução

| Campo | O que registrar |
| --- | --- |
| Identidade | ID do efeito, versão do motor, data, origem dos materiais, hashes da receita e do MP4 |
| Divergência | Frames `[início,fim)`, PTS, região, diferença observada; causa confirmada ou hipótese |
| Isolamento | Uma mudança por rodada; controle antes do encode e após decode; separar codec de erro criativo |
| Medição | Anterior → novo, unidade, limiar e regressões fora da máscara; RGB global não mede fidelidade entre cenas |
| Decisão | Verificado neste caso, aproximado, bloqueado, não testado, candidato a preset, reutilizável ou rejeitado |
| Próxima rodada | Como testar em material inédito; o que falta para validar e o que não deve voltar ao encaminhamento automático |

No modo autônomo, construa proxies autorais para gestos, profundidade e B-roll; não force uma cena incompatível a imitar outra com efeitos não observados. Use a [direção contextual](contextual-editing.md) apenas para o fluxo de aplicação ao bruto.
